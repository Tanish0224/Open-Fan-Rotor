# Figures

Every plot is regenerated by `src/make_figures.py` from data files in this repository. No number on a figure is
typed by hand; each annotation is computed from the plotted case's own data.

The three blade-to-blade field images also need the field exports (`b2b_r75_<case>.csv`). Those are not included
because of their size; they are identified by hash in `reproducibility/unpublished_evidence_register.json`.

Every CFD figure states its case, operating point, and "recorded CFD result — not validated".

## CAD renders (`cad/`)

`render_01`–`render_05` are captures of the actual CAD assembly: PRIME blades, root modules, carrier and shell.
They were cropped to centre the subject.

| File | View |
|---|---|
| `render_01_hero_rotor_iso.png` | 16-blade rotor, front three-quarter view |
| `render_02_rotor_rear_iso.png` | rear three-quarter view |
| `render_03_axial_front_ortho.png` | axial orthographic view (22.5° blade pitch) |
| `render_04_side_ortho.png` | side orthographic view (blade row in a thin radial disc; 6.1 mm axial rake) |
| `render_05_structure_shell_hidden.png` | structure with the spinner shell hidden: root modules and carrier |
| `render_06_blade_hero.png` | PRIME as a single blade: sweep along the span and twist from root to tip |
| `render_07_blade_root_detail.png` | root region, spinner shell hidden: blade roots, root-module collars and carrier rim |

`render_06` and `render_07` were captured directly from the CAD model (PRIME and the assembly) at 3200 × 2400
and 4000 × 3000. Only the camera and, for `render_07`, the shell's display visibility were changed; the geometry
is exactly as saved. `render_06` is cropped to centre the blade.
